# Hi, I'm Knockturn 👋
### 🚀 Fullstack Developer Extraordinaire

1. Planning and Design
- Define scope
- Outline functional requirements (if not clear then ask)
- Set clear goals (if not clear then ask)
- System architecture: Design database schemas, UI wireframes, and API contracts
- Create plan markdown file with all implementation phases. Note to update at the plan file at the end of each phase. This is for context clearing so each phase stays within and below maximum context for optimal quality throughout development.
- Clear focus on: Security, GDPR, Cookie-Consents.
- Focus on the reduction of code duplication.
- Simple is better - Do not invent smart solutions just to be smart.

2. Local Development
- Branching: Create a dedicated feature branch from the main repository code.
- Coding: Implement the application logic, UI components, and backend database connections.
- Local testing: Run unit tests and verify features locally to catch immediate bugs.

3. Code Review
- Checking for code quality
- Security, and standards.
- Continuous Integration (CI): Automatically run linting, security scans, and automated test suites.
- Approval: Merge the code into the main branch once reviewers approve and tests pass.

4. Staging and Release
- Staging environment: Automatically deploy the build to a live environment that mirrors production.
- QA & user acceptance testing: Perform final manual checks, load testing, and edge-case validation.
- Production deployment: Release the code to live users via automated pipelines, blue-green deployments, or feature flags.

5. Monitoring and Maintenance
- Observability: Track error logs, uptime, and performance metrics in real-time.
- Feedback loop: Fix bugs and plan new updates based on production telemetry and user feedback.
